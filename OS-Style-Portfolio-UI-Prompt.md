# OS-Style Portfolio UI

## Overview

Create a desktop operating system--inspired interface with a terminal
aesthetic.

------------------------------------------------------------------------

# Overall Theme

-   Full-screen background color: **#0A0A0A**
-   Use **Geist Mono** as the primary font throughout the interface.
-   The entire UI should resemble a minimalist terminal.
-   Keep the interface flat with **no rounded corners**.
-   Use subtle animations and maintain a clean, minimal design language.

------------------------------------------------------------------------

# Top Menu Bar

Create a full-width menu bar fixed at the top of the screen.

## Left Section

Display:

-   Company Logo
-   Company Name: **VONNUE**

Use **Geist Mono** for the company name.

------------------------------------------------------------------------

## Menu Items

### File

-   Share on FB
-   Share on Twitter
-   Close Window

### Go

-   Works
-   Portfolio

### View

-   Change Background

### Help

-   Report a Bug

------------------------------------------------------------------------

# Company Logo Dropdown

Clicking the company logo should open a dropdown menu.

The dropdown should have proper open/close interactions and close when
clicking outside.

## Menu Items

-   About Vonnue
-   Behance
-   Dribbble
-   LinkedIn
-   Instagram
-   Email
-   Shutdown

------------------------------------------------------------------------

# Shutdown Interaction

When **Shutdown** is selected:

1.  Play a smooth fullscreen black shutdown animation.
2.  The screen should remain black.
3.  Clicking anywhere or pressing any keyboard key should boot the
    system again.
4.  Replay the boot sequence before returning to the desktop.

------------------------------------------------------------------------

# Right Section

Display system information aligned to the right side of the menu bar.

## Custom Clock

``` text
37:85:56
DAY BREAKDOWN
```

Supporting text:

``` text
"WTF IS THIS? 10 MY_WORK"
```

### Description

Instead of a traditional 24-hour clock, display a conceptual clock where
a day is divided into **150 weighted hours (-25 to 125)**. Each hour
represents perceived time rather than actual elapsed time.

------------------------------------------------------------------------

# Year Progress

Display a compact system widget containing:

-   Year Phase
-   58% Balance
-   Working Illustration
-   Progress:

``` text
212 / 365
```

------------------------------------------------------------------------

# Design Principles

-   Terminal-inspired desktop experience.
-   Flat interface.
-   Sharp corners (no border radius).
-   Monospace typography using **Geist Mono**.
-   Minimal visual noise.
-   Smooth and lightweight interactions.
-   Professional OS-like layout.
-   Consistent spacing and alignment.
-   Responsive desktop-first design.
